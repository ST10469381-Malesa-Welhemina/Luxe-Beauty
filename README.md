# Luxe Beauty Website

## About This Project

This is a website for Luxe Beauty, a beauty brand based in South Africa. It has five pages: Home, About, Products, Enquiry, and Contact.

I built the HTML structure in Part 1. In Part 2, I added CSS styling and made the site responsive so it works on phones, tablets, and computers.

## What The Site Does

- Shows beauty products with pictures, prices, and descriptions.
- Lets people send an enquiry about products or advice.
- Gives contact details for two branches (Johannesburg and Pretoria).
- Shows opening hours and a map.
- Links to social media pages.

## Responsive Design

I added media queries so the site changes on smaller screens.

- On desktop: normal layout.
- On tablet: navigation wraps, fonts get smaller.
- On mobile : everything stacks in one column, navigation stacks, product grid becomes one column.
